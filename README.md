# Flesh and Fur - Interactive Data Visualization

An interactive data journalism piece exploring tiger conservation, illegal wildlife trade, and the ongoing fight to protect endangered tigers worldwide.

## Features

✨ **Interactive Visualizations**
- Dynamic Plotly charts with hover interactions
- Geographic choropleth and scatter maps
- Animated bar charts and line graphs

🎨 **Engaging User Experience**
- Scroll-triggered animations (fade-in, slide-in effects)
- Parallax background effects
- Animated number counters for statistics
- Reading progress bar
- Smooth scrolling navigation
- Micro-interactions and hover effects

📱 **Responsive Design**
- Optimized for desktop, tablet, and mobile devices
- Adaptive layouts for all screen sizes
- Performance optimized with reduced motion support

## Technologies Used

- HTML5 / CSS3
- JavaScript (ES6+)
- [Plotly.js](https://plotly.com/javascript/) for data visualizations
- Google Fonts (Epilogue)

## Local Development

To run this project locally:

1. Clone the repository
```bash
git clone https://github.com/KongJinOng/fleshnfur-copy.git
cd fleshnfur-copy
```

2. Start a local server
```bash
python3 -m http.server 8000
```

3. Open your browser and navigate to `http://localhost:8000`

## Data Sources

The visualizations are based on data about:
- Global tiger population trends
- Tiger Range Countries (TRCs)
- Illegal wildlife trade seizures
- Captive tiger breeding statistics
- Online trafficking activities

## Conservation Message

This project aims to raise awareness about:
- The dramatic decline in wild tiger populations
- The impact of illegal wildlife trade
- Policy loopholes that enable poaching
- How individuals can contribute to tiger conservation
